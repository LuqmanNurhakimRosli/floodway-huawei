FloodWay river node (IoT water depth)

Ultrasonic sensor above the water, reads the distance to the surface. The server turns distance into depth.

1 · Ultrasonic sensor (JSN-SR04T) Waterproof, mounted above the water, pointing down. Reads the distance to the surface.
Firmware written · bench-tested
2 · ESP32 controller and Wi-Fi Takes the median of 9 readings, signs the packet, sends it over HTTPS to /api/v1/ingest.
Firmware written · Wi-Fi link
3 · Solar panel and battery Off-grid power for the node. Battery sizing and weatherproofing still to be tested.
Planned · not built
4 · Server converts distance to depth Depth = mount height − measured distance. Mount height is set on the server, so the sensor can be recalibrated without reflashing.
