# FloodWay — Project Context

## What Is FloodWay?

FloodWay is an **AI-powered flood preparedness and emergency response system** for Malaysia. It combines real-time IoT sensor data, machine learning predictions, community-sourced reports, and turn-by-turn shelter navigation into a single mobile-first web application.

## Why It Exists

Malaysia experiences catastrophic flooding annually, particularly in Kuala Lumpur and the Klang Valley. Citizens lack a unified platform that:
- Predicts flooding before it happens
- Alerts them in real-time based on proximity
- Guides them to verified emergency shelters via safe routes
- Lets communities report flood conditions for collective awareness

FloodWay solves all four problems.

## Core Value Proposition

> "One glance to know if you're safe. One tap to find shelter."

The app uses a **Traffic Light System** (Green/Yellow/Red) as its primary UX pattern — users instantly understand their risk level without reading technical data.

## Geographic Focus

- **Primary**: Kuala Lumpur, Wilayah Persekutuan
- **Extended**: Selangor (Petaling Jaya, Shah Alam, Kajang, Klang, Puchong, Batu Caves, Sungai Buloh, Seri Kembangan)
- **IoT Sensor**: Klang River near Masjid Jamek (lat: 3.149, lng: 101.696)
- **Default User Position**: KLCC area (lat: 3.1542, lng: 101.7148)
